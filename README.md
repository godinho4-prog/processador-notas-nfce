# Processador de notas NFC-e

Processador automático da fila de NFC-e do app pessoal de preços.

O repositório contém apenas o código necessário para:

1. verificar se existem notas aguardando no Firestore;
2. abrir a página pública da SEFAZ-RJ com Playwright;
3. extrair os dados;
4. gravar o resultado no Firestore.

Credenciais, links de notas, arquivos de debug e dados pessoais não fazem parte do repositório.
